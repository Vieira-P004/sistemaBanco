# 💳 Sistema Bancário em Java

Projeto simples desenvolvido em Java com o objetivo de praticar os conceitos básicos de Programação Orientada a Objetos (POO).



## 🚀 Funcionalidades


* ✅ Criar conta bancária


* 💰 Realizar depósitos


* 🏧 Realizar saques


* 📋 Exibir dados da conta


* 🔒 Validação básica de saldo



## 🛠️ Conceitos praticados
Este projeto utiliza conceitos importantes da linguagem Java:


* Classes e Objetos

* Construtor

* Métodos

* Atributos

* Uso do this

* Encapsulamento inicial

* Manipulação de saldo


## 📂 Estrutura do Projeto

```
SistemaBancario/
│
├── SistemaBancario.java
```
## ▶️ Como executar


1 - Compile o arquivo:

```
javac SistemaBancario.java
```

2 - Execute o programa:

```
java SistemaBancario
```
